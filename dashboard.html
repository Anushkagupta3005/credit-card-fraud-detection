What drives a fraud flag

TreeSHAP on the tuned model — exact Shapley values. The features are PCA components, so these show which signal moved a decision, computed on a fraud-enriched sample.

Method. 80/20 stratified split locked at the start; all tuning and threshold selection via stratified cross-validation on the training set only. The test set was opened once, at the end. Metric is PR-AUC, since accuracy is meaningless at a 0.17% fraud rate. The cost-optimal threshold (0.044) was chosen on out-of-fold training scores before the holdout was touched. Cost model — $100 per missed fraud, $10 per false alarm — is an illustrative assumption; the method generalizes to any ratio.

Reproducibility. random_state=42 throughout · seeds fixed · holdout opened exactly once. Numbers on this page are read directly from the notebook run that produced it.
